# المتجر — 3A Store

متجر ملابس مصري من الصفر: React + TypeScript + Supabase (Postgres + RLS) + Vercel.
عربي RTL من الجذر، موبايل أولًا، الدفع عند الاستلام فقط.

- الخطة والحزم ١–٥: `docs/PLAN.md`
- فحص الأسرار: `docs/SECRET-SCAN.md`
- السكيما وRLS وآلة حالات الطلب: `supabase/migrations/0001_schema.sql`

تشغيل محلي: `npm install` ثم `npm run dev` — وانسخ `.env.example` إلى `.env.local` بقيم مشروع Supabase الجديد.
